# 시트 정리 프로그램

RMA 시트의 특정 열을 골라서 다른 시트(SYSTEM 시트 등)로 옮겨주는 tkinter 기반 데스크톱 도구입니다.

## 배경

- 원래는 `=IF(RMA!M3="","",RMA!M3)` 같은 수식으로 RMA 시트의 열을 SYSTEM 시트에 하나씩 옮겨 적었음
- 문제는 열 순서/이름이 자주 바뀐다는 것 — 셀 위치(M3 등)를 기준으로 한 수식이라 열이 하나만 옮겨져도 수식이 깨짐
- 그래서 셀 위치가 아니라 **열 이름 기준 매칭**으로 다시 설계하기로 결정
- 자동화 방법으로 엑셀 매크로(VBA)도 고려했지만, 최종적으로는 **파이썬 독립 프로그램(GUI)** 형태로 만들기로 결정
  (엑셀 파일/매크로 보안 설정에 영향받지 않고, 파일이 열려 있어도 미리보기가 가능한 등 다루기 편해서)
- 이후 실제 사용하면서 v1 → v2 → v3로 기능을 늘려왔음 (아래 "개발 히스토리" 참고)

## 이런 분께 필요합니다

- RMA(반품/수리) 시트에서 매번 같은 열들을 골라 다른 시트로 옮겨 적는 반복 작업을 하고 있다면
- 옮길 열이 이름/번호로 자주 바뀌어서 수식이 자꾸 깨진다면
- 엑셀을 열어둔 채로 결과를 먼저 확인하고, 확실할 때만 저장하고 싶다면

## 실행 방법

### 1. 빌드된 exe로 실행 (Python 설치 불필요)

`dist/시트정리프로그램.exe` 를 더블클릭하면 바로 실행됩니다.

### 2. 소스로 직접 실행 (개발/수정 시)

```powershell
# 최초 1회: 가상환경 생성 + 라이브러리 설치
python -m venv .venv
.venv\Scripts\activate
pip install openpyxl

# 실행
python 엑셀_정리_프로그램.py
```

## 사용법

1. **엑셀 파일 선택**: "찾아보기"로 RMA 시트가 들어있는 `.xlsx`/`.xlsm` 파일을 선택합니다.
   선택하면 파일 안의 시트 목록이 자동으로 표시됩니다.
2. **원본 시트 설정**
   - 가져올 시트 이름: 기본값은 "RMA"이며, 이름에 "RMA"가 들어간 시트가 있으면 자동으로 선택됩니다.
   - 헤더(열 제목) 행 번호: 열 제목이 있는 행 번호를 입력합니다. (예: 2행이 제목이면 `2` → 데이터는 3행부터 자동으로 읽음)
   - 가져올 열: 비워두면 기본 15개 열(No., 계약년, SYSTEM, 구분, 관리국, SITE 등)을 사용합니다.
     직접 지정하려면 다음 세 가지 방식 중 아무거나 콤마로 나열하면 됩니다.
     - 열 이름: `관리국,SITE,유니트명`
     - 열 번호: `1,3,5`
     - 열 문자: `A,C,E`
3. **결과를 저장할 위치**
   - 새 시트 만들기: 지정한 이름으로 새 시트를 생성합니다. (이름이 중복되면 자동으로 `_1`, `_2`가 붙습니다)
   - 기존 시트에 이어서 추가: 기존 시트의 헤더와 이름을 맞춰서 그 열 위치에 이어서 채웁니다.
     기존 시트에 없는 열은 자동으로 맨 뒤에 추가됩니다.
4. **복사 옵션**
   - 서식(글자색/배경색/테두리/표시형식)도 함께 복사할지 여부
   - 원본이 수식이면 값 대신 수식 자체를 복사할지 여부
5. **미리보기 / 실행**
   - **미리보기**: 저장하지 않고 결과를 화면 표로 먼저 확인합니다. 엑셀 파일이 열려 있어도 항상 가능합니다.
     이번에 실제로 채워지는 열은 제목에 `★`가 표시됩니다.
   - **실행**: 실제로 원본 파일에 저장합니다. **이때는 엑셀에서 해당 파일을 닫아둬야 합니다** (열려 있으면 저장 시 오류가 날 수 있습니다).
6. **원본 시트 보기 탭**: 아무 시트나 골라서 엑셀처럼 행 번호/열 문자와 함께 실제 내용을 확인할 수 있습니다.
   표에서 행을 클릭하면 그 행 전체 내용이 아래에 펼쳐져서 보입니다.

## 파일 구조

```
엑셀_정리_프로그램.py   GUI (tkinter) - 화면 구성, 사용자 입력, 버튼 동작
core.py                핵심 로직 - 엑셀 읽기/쓰기, 열 이름 매칭, 데이터 복사 (GUI에 의존하지 않음)
시트정리프로그램.spec   PyInstaller 빌드 설정
dist/                  빌드된 exe (git 추적 대상 아님)
build/                 PyInstaller 빌드 중간 산출물 (git 추적 대상 아님)
```

로직(`core.py`)과 화면(`엑셀_정리_프로그램.py`)을 분리해둔 이유는, 앞으로 기능이 늘어날 때
화면 코드를 건드리지 않고 로직만 수정/테스트할 수 있게 하기 위해서입니다.

## 테스트 실행

`core.py`의 로직 함수들에 대한 최소 단위 테스트가 `test_core.py`에 있습니다. (화면 없이 함수 단위로 확인)

```powershell
pip install pytest
pytest
```

## exe 빌드 방법

```powershell
pip install pyinstaller
pyinstaller --onefile --windowed --name "시트정리프로그램" 엑셀_정리_프로그램.py
```

- `--onefile`: 파일 하나로 압축 (같은 폴더의 `core.py`는 자동으로 함께 포함됩니다)
- `--windowed`: 실행 시 콘솔창 없이 GUI 창만 뜸
- 완료되면 `dist\시트정리프로그램.exe` 생성됨
- `build` 폴더는 매번 새로 생기는 중간 산출물이라 지워도 무방합니다
- 백신이 처음 보는 exe를 경고할 수 있습니다 → 예외 처리 또는 IT 담당자 확인 필요

## 개발 히스토리 (요약)

1. **v1**: 고정된 15개 열을 새 시트에만 생성하는 기본 버전
2. **v2**: 열 이름/번호/문자로 원하는 열 직접 지정, 기존 시트에 이어 붙이기, 수식/서식 복사 옵션 추가
3. **v3**: 미리보기 기능(저장 전 결과 확인), 원본 시트 보기 탭, 시트 목록 자동 동기화, 실행 후 자동 새로고침
4. **버그 수정**: "기존 시트에 이어서 추가" 시 다른 열 데이터 때문에 행이 밀리던 문제 → 이번에 실제로 채우는 열 기준으로만 마지막 행을 찾도록 수정
